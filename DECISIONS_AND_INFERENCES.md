# Decisions and inferences log

Every place where we regroup, calculate, infer, or assume goes here, **before** the number is used in a chart. If a viewer figure depends on a choice that is not in this file, that is a bug. This file is meant to be published with the viewer (GitHub `docs/`), so write entries for a skeptical reader, not for us.

## Rules
1. **Raw first.** Charts default to values as reported by the source. Anything else is a labeled overlay the reader turns on.
2. **Every figure carries a tag**, shown on the chart and carried in the data as a `derivation` column:
   - `RAW`: value as published by the source.
   - `REGROUPED`: raw values summed under our category map. Nothing is estimated, but the grouping is a choice.
   - `CALCULATED`: arithmetic on raw values (ratios, per-pupil, index to a base year, inflation adjustment, % change).
   - `INFERRED`: depends on a guess about what the data means (linking people across years, aligning a series to school years, treating a label as a period).
   - `EXTERNAL`: taken from someone else's analysis (community spreadsheets, district statements). Not verified by us unless stated.
3. **Each chart lists the entry IDs it depends on** in its footer, linked to this file.
4. **Each entry has:** what we did, why, the alternative, how much it could matter, and status (`confirmed` by a source, `assumed`, `open`).
5. Scripts in `tools/` cite entry IDs in comments. Decisions made in code but missing here are bugs.
6. Corrections are added as new entries or marked superseded. Nothing is deleted.
